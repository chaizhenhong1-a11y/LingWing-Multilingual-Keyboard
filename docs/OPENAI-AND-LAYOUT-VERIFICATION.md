## Keyboard layouts

This milestone contains 59 language categories and 77 layout schemes, with composing input for Chinese, Japanese, Korean and Vietnamese. See COMMON-LANGUAGE-COVERAGE.md/json for precise capability limits and data provenance. Prior seven-layout description below is historical.

Tap the far-right active keyboard language (English initially) to choose a bundled layout: English, Thai, Russian, Ukrainian, Arabic, Greek, Hebrew. This changes actual keys and persists separately from translation target. Direct character input only; no predictive lexicon, glide typing, speech, or CJK composition engine. Number corner hints map first ten top-row character keys to 1–0; long press inserts the digit. Emoji panel contains 24 bundled common emoji. Physical-device acceptance remains pending.

## Use

Install the updated APK, open LazyTalk Settings, select 使用 Google Cloud 连接, paste the separate cloud access code and save the connection. The configured cloud route needs phone internet but no computer or USB. USB development remains available separately. Live translation runs after a 500ms typing pause in Remote mode, updates only its tracked input range, and never sends. See backend/cloud/README.md.

The copied-sentence flow uses a bundled local ML Kit model and does not use AccessibilityService or clipboard listeners. Model-result tests use a fake detector; real native identification on the phone remains unverified. See COPIED-SENTENCE-IDENTIFICATION.md. Physical phone acceptance is pending; tool-side ADB cannot see the host phone. Landscape layout was checked with Robolectric Compose tests, not a physical device.
