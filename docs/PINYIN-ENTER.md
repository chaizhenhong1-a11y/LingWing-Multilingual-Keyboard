# LingWing Keyboard 0.5.6

Chinese Pinyin stays in the keyboard candidate area and emits no composing text into the host editor before confirmation. Backspace edits only the pending Pinyin. Enter commits the raw letters (for example zh) without choosing the first candidate or submitting the host editor. Space and candidate taps retain Chinese selection behavior. Tested before and after candidate loading and at the translation draft caret.
